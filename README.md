# 个人成长工作台 · Personal Growth Workbench 🌱

一个薄荷绿清新风格的**个人成长记录工作台**，纯静态前端工程（HTML + CSS + 原生 JS，零依赖）。

## ✨ 功能模块

- 🏠 **首页**：成长概览、本周趋势、模块投入占比、成长日历、核心模块入口
- 👤 **个人面板**：全维度成长总览、模块熟练度、成长记录
- 📅 **每日计划**：上午/下午任务安排
- 💄 **妆容穿搭灵感**：变美进度、穿搭推荐、妆容步骤
- 🍱 **饮食**：喝水进度、营养占比、推荐食谱
- 💪 **健身**：运动数据、跟练推荐、本周趋势
- 💃 **舞蹈**：跟练推荐、动作拆解、练习安排
- 🎨 **绘画**：专注番茄钟、素材灵感、练习记录
- 🌿 **养生知识** / 🍵 **中医养生** / 🇫🇷 **法语学习** / 📷 **拍摄剪辑练习**
- 🔮 **塔罗星盘**：每日抽牌（可点击翻牌）、牌意学习
- 🧁 **烘焙小店**：配方步骤、原料库存、出品记录
- ⚙️ **设置**

## 🎨 特性

- 纯 SVG 图表（折线图 / 环形图 / 柱状图 / 进度环），无任何外部依赖
- 单页应用（SPA）式页面切换，数据驱动渲染
- 番茄钟计时、塔罗翻牌、清单勾选等轻交互
- 响应式布局，移动端自适应

## 🚀 本地启动

无需安装任何依赖，任选其一：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

然后浏览器打开 http://localhost:8080 即可。

> 💡 数据均为演示用模拟数据，可在 `js/data.js` 中自由修改。
